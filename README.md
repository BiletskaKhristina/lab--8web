# Акустична варта — Професійний акустичний моніторинг

Навчальний вебпроєкт, спрямований на моніторинг та аналіз рівня шуму в міських умовах. Проєкт розробляється в межах виконання лабораторних робіт з дисципліни **«WEB-програмування»**.

---

## 🛠 Технології та стек

- **HTML5 / CSS3 / SASS** — структура сторінки та стилізація
- **TypeScript** — типізація даних, розробка логіки (`src/sensors.ts`)
- **JavaScript (ES6+)** — скомпільований код у папці `dist/`
- **REST API (MockAPI)** — серверна симуляція для отримання даних про сенсори
- **Git / GitHub** — контроль версій

---

## 📋 Функціонал (Лабораторна робота №6)

1. **Типізація даних:** Описано інтерфейс `Sensor` для структури об'єктів (id, назва, район, рівень шуму, статус).
2. **Асинхронні запити:** Використання `async/await` та `fetch()` для завантаження даних із MockAPI.
3. **Обробка помилок:** Перевірка успішності відповіді сервера (`response.ok`) та перехоплення помилок через `try/catch`.
4. **Динамічний рендеринг DOM:** Генерація карток сенсорів на основі отриманого типізованого масиву `Sensor[]`.
5. **Фільтрація:** Автоматична фільтрація сенсорів за адміністративним районом та рівнем шуму (критичністю).

---

## 🚀 Як запутнити проєкт локально

1. Клонуйте репозиторій або відкрийте папки проєкту в **VS Code**.
2. Встановіть необхідні залежності (TypeScript):
   ```bash

   ```
